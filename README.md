A robot vacuum's deadpan alibi for a missed spot, in a single line of 109 characters: it denies missing the spot at all, reports that its sensors classified the crumb as load-bearing, and explains it is not licensed to demolish crumbs. The program prints exactly that line (and writes it to `/output/entry.txt`, where the competition's gate reads it) and nothing else.

## Run it

```sh
node main.ts
```
